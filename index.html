구글 시트 · 엑셀 실시간 연동

응답이 제출될 때마다 구글 시트에 한 줄씩 자동으로 쌓입니다. 구글 시트는 엑셀로 바로 열 수 있습니다. (무료)

버튼 한 번으로 새 시트를 만들고 자동 연동
클라이언트 ID 만드는 법 (무료, 약 5분)
  1. console.cloud.google.com에서 프로젝트를 만듭니다.
  2. API 및 서비스 → 라이브러리에서 Google Sheets API와 Apps Script API를 사용 설정합니다.
  3. OAuth 동의 화면: 사용자 유형 외부, 본인 계정을 테스트 사용자로 추가합니다.
  4. 사용자 인증 정보 → OAuth 클라이언트 ID → 웹 애플리케이션, 승인된 JavaScript 원본에 이 페이지 주소를 추가합니다. (예: https://terafugen-cx.github.io)
  5. script.google.com/home/usersettings에서 Google Apps Script API를 켭니다.
수동 방식 (Apps Script 직접 붙여넣기)
  1. 구글 시트를 새로 만들고 확장 프로그램 → Apps Script를 엽니다.
  2. 아래 코드를 복사해 기존 내용을 지우고 붙여넣은 뒤 저장합니다.
  3. 배포 → 새 배포 → 웹 앱: 실행 사용자 나, 액세스 권한 모든 사용자로 배포하고 승인합니다.
  4. 나온 웹 앱 URL을 편집 화면 오른쪽 구글 시트 연동 URL에 붙여넣습니다.
  5. 엑셀에서 쓰려면 시트의 파일 → 다운로드 → .xlsx, 또는 파일 → 공유 → 웹에 게시 → CSV 링크를 엑셀 데이터 → 웹에서로 연결하면 갱신됩니다.
